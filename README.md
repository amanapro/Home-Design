# Benchmark Planner

Floor plans, wall elevations, 3D and quantity takeoff for interior designers, contractors and renovators, with kitchen and bath fixtures. One codebase, three ways to install it:

| Target | What you get | How it's built |
|---|---|---|
| Windows | `.msi` and `.exe` installer | Tauri, on GitHub Actions or a Windows PC |
| macOS | `.dmg` (Intel + Apple Silicon) | Tauri, on GitHub Actions or a Mac |
| Linux | `.deb`, `.rpm`, `.AppImage` | Tauri, on GitHub Actions or Linux |
| Android | `.apk` | Tauri, on GitHub Actions or a PC with Android Studio |
| Any browser | Installable web app (PWA), works offline | Upload `src/` to any HTTPS host |

## Project layout

```
src/                  The whole app. Plain HTML/CSS/JS, no build step, no npm packages.
  index.html          Page structure
  app.css             Styles (light and dark themes)
  app.js              Drawing, geometry, rooms, elevations, takeoff, 3D, file open/save
  vendor/three.min.js 3D library (three.js r128), bundled so the app works offline
  fonts/              IBM Plex Sans/Mono and Barlow Condensed (OFL), bundled for offline
  manifest.webmanifest, sw.js   Only used by the browser-installed version
src-tauri/            Native shell (Rust). You rarely need to touch this.
  tauri.conf.json     App name, version, window size, bundle settings
  capabilities/       What the web UI may call: open/save dialogs and reading/writing chosen files
  gen/android/        Android Studio project (generated by Tauri, signing config added)
  icons/              All app icons, generated from assets/app-icon.png
.github/workflows/build.yml   Builds every installer in the cloud
```

To change the app, edit files in `src/`. To change the version, update it in both `package.json` and `src-tauri/tauri.conf.json` (and `VERSION` in `src/sw.js` for the web version).

## Easiest path: let GitHub build everything

1. Create a GitHub repository (private is fine) and push this folder to it.
2. Open the repository's **Actions** tab, choose **Build apps**, then **Run workflow**.
3. After about 15–25 minutes:
   - Windows, macOS and Linux installers are in a **draft release** under **Releases**.
   - Every installer, including the Android APK, is also under the finished run's **Artifacts**.

Pushing a tag such as `v0.2.0` runs the same build.

### Android signing

Without any setup the APK is signed with a temporary debug key. It installs fine for testing (allow "Install unknown apps" on the phone), but a later build can't update it in place; uninstall first.

For real releases, create your own key once and keep it safe, since losing it means you can never update the app on users' phones:

```
keytool -genkey -v -keystore benchmark-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

Then add three repository secrets (**Settings → Secrets and variables → Actions**):

- `ANDROID_KEY_BASE64`: the keystore file as base64 (`base64 -w0 benchmark-upload.jks` on Linux, `certutil -encode` on Windows, then remove the header and footer lines)
- `ANDROID_KEY_PASSWORD`: the keystore password
- `ANDROID_KEY_ALIAS`: `upload`

## Building on your own computer

You need **Rust** (https://rustup.rs) and **Node.js 18+** (only for the Tauri command-line tool). Then, in this folder:

```
npm install
npm run dev        # opens the app in a window with live reload of src/
npm run build      # makes the installer for the computer you're on
```

Installers land in `src-tauri/target/release/bundle/`.

Per platform you also need:

- **Windows**: Microsoft C++ Build Tools ("Desktop development with C++"). WebView2 is already on Windows 10/11; the installer downloads it if missing.
- **macOS**: Xcode Command Line Tools (`xcode-select --install`).
- **Linux (Debian/Ubuntu)**: `sudo apt install libwebkit2gtk-4.1-dev build-essential libssl-dev libxdo-dev libayatana-appindicator3-dev librsvg2-dev`
- **Android**: Android Studio (it includes the SDK and a suitable Java), plus NDK `27.0.12077973` from Android Studio's SDK Manager, then
  ```
  rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
  set ANDROID_HOME and NDK_HOME (see https://v2.tauri.app/start/prerequisites/#android)
  npm run android:dev    # run on a connected phone or emulator
  npm run android:apk    # build the APK
  ```
  The APK is in `src-tauri/gen/android/app/build/outputs/apk/`. For local signing, put a `keystore.properties` file (with `password`, `keyAlias`, `storeFile`) in `src-tauri/gen/android/`.

## Web version (PWA)

Upload the contents of `src/` to any HTTPS site (for example `https://plan.example.com/`). In Chrome or Edge on a computer, or Chrome on Android, an **Install** option appears in the address bar or menu. After the first visit it works offline. In the browser, Save downloads a `.bench.json` file and Open uses the normal file picker.

## Files

Everything is under the **File** menu.

- **Save / Open project**: projects are `.bench.json` files (plain JSON: walls, openings, fixtures, room names, tiling settings and any reference drawing). `Ctrl+S` saves, `Ctrl+Shift+S` saves as, `Ctrl+O` opens.
- **Tabs:** several projects can be open at once, each in its own tab under the top bar with its own drawing, undo history, imported reference and file.
  - **+** (or **File → New project**) opens a blank project or the sample in a new tab.
  - **Open project** opens the file in a new tab; if the current tab is still empty, the file takes its place.
  - Click a tab to switch, and **×** (or a middle-click) to close it. A dot marks unsaved changes, and closing such a tab asks whether to save.
- **Autosave:** every 5 minutes, any project that has been saved to a file and has changes is written back to that file (installed app). The time of the last save shows at the right of the tab bar. Turn it on or off in the File menu.
- All open tabs, including unsaved ones, are also kept on this device and come back the next time the app starts. In a browser, which can't write to your files silently, this is the autosave; use **Save project** to keep a file.

### PDF and images

**Export plan as PDF or image** (`Ctrl+P`) puts the plan on a sheet of paper, ready to print, email or put in a report:

- **Format:** PDF, PNG or JPG.
- **Paper:** A4, A3, A2, A1, Letter or Tabloid, landscape or portrait (picked automatically from the shape of the plan).
- **Scale:** fit to the sheet, or a true scale from 1:20 to 1:500. The dialog tells you when a scale doesn't fit and which one does.
- **Quality:** 150, 200 or 300 dpi.
- **Colours:** white paper for printing, or as on screen.
- **Options:**
  - a title block with the project name, date, scale and a scale bar
  - the grid
  - the imported picture or drawing
  - the 3D view on a second PDF page
- A live preview shows the sheet before you save.
- Measurements on the sheet follow the **Measures** menu.

The desktop app needs the `fs:allow-write-file` permission (already in `src-tauri/capabilities/default.json`) to save PDFs and images.

### AutoCAD

AutoCAD's own DWG format is closed, so the app exchanges **DXF**, which AutoCAD opens and saves directly.

**Import from AutoCAD (DXF)** (`Ctrl+I`) reads ASCII DXF from AutoCAD R12 up to 2018 and later:

- Lines, polylines (including arcs inside polylines), arcs, circles, ellipses, splines, text and multiline text, blocks (doors, furniture, title blocks; nested, rotated, mirrored, arrays) and dimensions.
- Units come from the file; when the file doesn't say, they're guessed from its size. The dialog shows the resulting building size so you can correct it.
- Arabic and other non-Latin text is read from both new (UTF-8) and old (Windows code page, e.g. ANSI_1256) files.
- Each layer is set to **Walls**, **Reference** or **Skip**. Layers named like walls (wall, A-WALL, جدار, جدران, حائط…) are picked automatically; otherwise the layer with the most double-line walls is.
- On wall layers, pairs of parallel lines become real walls with the right thickness. Corners and T-junctions are closed, door swings in the gaps become doors (with the swing side and hinge), and glazing lines become windows. Text inside a room becomes its name, and the room type is guessed from it (kitchen/مطبخ, bath/حمام, …).
- Everything set to Reference stays under the plan as a faint **reference drawing** to trace over; line ends snap. Toggle it with the **Reference** button on the plan, remove it from the File menu.
- Walls drawn as single lines, hatches and images are not converted. Trace single-line walls with the Wall tool.
- DWG files are recognised and you're told how to convert them: in AutoCAD use **Save As → AutoCAD 2018 DXF**, or use the free **ODA File Converter**.

**Export to AutoCAD (DXF)** (`Ctrl+E`) writes an AutoCAD R12 ASCII DXF, which every AutoCAD release opens, as do BricsCAD, DraftSight, LibreCAD, ArchiCAD, Revit and SketchUp Pro:

- Choose millimetres, centimetres, metres or inches; the file's units are set so it inserts at the right size.
- Walls are clean outlines (`A-WALL`) with proper corners, cut at every door and window. Doors with swing arcs (`A-DOOR`), windows (`A-GLAZ`), fixtures (`A-FURN`, wall cabinets dashed on `A-FURN-UPPR`), room names and areas (`A-AREA-IDEN`), outside dimensions (`A-ANNO-DIMS`), and optionally the reference drawing (`REF-…`).
- Non-Latin text such as Arabic room names is written with AutoCAD's `\U+` Unicode codes, which AutoCAD decodes.
- Exported files import back into the app exactly.

### Plan images and PDFs

**Import plan image or PDF** (File menu) brings in a scanned plan, a photo of a drawing, a screenshot, or a PDF page (PNG, JPG, WebP, GIF, BMP, PDF; for a PDF with several pages, choose the page):

1. **Scale from one wall.** Click both ends of a wall whose length you know, or both ends of a dimension, and type the real length. A magnifier follows the pointer for accurate clicks. You can drag the two points to adjust them; scroll or pinch to zoom, and drag to move around. If that wall is slightly crooked, the plan is straightened to it. Any small tilt left over is corrected from the walls themselves.
2. **Walls.** The walls are found from their thickness. Thin lines (furniture, kitchen and bath fixtures, text, dimensions, door swings, floor patterns) are left out. Choose how the walls are drawn (filled solid, hatched, or two lines), their colour, and the thinnest and thickest wall. The walls found show in blue and doors and windows in orange, before you import.
   - Gaps between wall ends become doors when a swing arc is there, with the hinge and swing side read from the arc. They become windows when glazing lines cross the gap.
   - Wall thickness is measured and rounded to 10 mm.
3. **Crop to the plan** (optional). Drag a box around the plan to leave out a title block, legend or a second drawing on the same sheet.

**Under the plan** decides what stays under the drawing as a faint **reference image**, scaled, straightened and lined up with the walls. The choices are **Walls only** (the default), **The whole picture**, or **Nothing**. Walls only keeps just the thick wall shapes from the picture; dimensions, furniture, appliances, fixtures, text and the sheet border are dropped. Use it to spot and trace any wall that was missed. **Reference** on the plan shows or hides it. **Remove reference drawing or image** in the File menu deletes it. The image is saved in the project file.

Works best with: a clear scan or PDF in which walls are visibly thicker than other lines, and walls that are straight. Expect to tidy up:

- curved walls and walls at an angle other than 90° (these may come in as a few short pieces)
- furniture or fixtures drawn tight against a wall in two-line drawings (the wall may come in thicker there)
- photos taken at an angle (only flat scans and PDFs are true to scale)
- iPhone HEIC photos (export as JPG first)
- room names (these aren't read from the image; click a room to name it)

### Electrical layer: lights, switches and sockets

- The **Electrical** section in the tool panel has **Spot light**, **Strip light**, **Chandelier**, **Wall light** and **Garden light**; **Switch** and **Dimmer**; **Socket** and **Outdoor socket**.
- Spot lights, chandeliers and garden lights: click where they go. Strip lights: click the start and the end (snaps to angles; `Shift` for any angle). Wall lights, switches and sockets: click on a wall face; they sit on the side you click and slide along the wall when dragged.
- The **Electrical** button above the plan shows or hides the whole layer (hidden parts can't be selected, and they leave 3D, elevations and exports too). Picking an electrical tool shows it again.
- Select one to change it: switch gangs (1–4), single or double socket, height to centre (switches 1,100 mm, sockets 300 mm, wall lights 1,800 mm to start), strip length and height, chandelier drop, and a label such as a circuit name.
- Wall-mounted parts appear in the room's elevations at their height. The fixture schedule counts each kind, switch gangs and socket outlets, and adds up strip-light length. AutoCAD export puts lights on `E-LITE` and switches and sockets on `E-POWR`.
- While placing spot lights, chandeliers, garden lights and strip lights, dimension lines show the distance to the nearest wall faces (across x and y; for a strip, from its side and both ends). They also show when one is selected.
- Several at once: drag a box around them (with Box select on), or `Ctrl`/`Shift`+click to add or remove. Drag any of them to move them all, use the arrow keys, or press `Del`.
- When **Electrical** is off its tools are greyed out; turn it on to use them.
- In 3D, plates and wall lights show on the walls, garden lights stand in the yard, and from inside (Walk) the spot lights, chandeliers and strips show on the ceiling. At **Night** these lights switch on in place of the default room light.

### 3D: realistic look and walking inside

- **Walk** (top right of the 3D view), **Walk inside** in a room's side panel, or double-click a floor in 3D puts you inside at eye level (1.6 m). Walk with `W` `A` `S` `D` or the arrow keys (`Q`/`E` or left/right arrows turn, `Shift` goes faster), drag to look around, scroll to step. On phones and tablets use the on-screen joystick and drag to look. Walls, fixtures and furniture stop you; door openings let you through. **Go to room** jumps to any room, and the plan shows where you stand and which way you look. `Esc` or **Orbit** goes back to the outside view.
- Materials are drawn by the app itself (no picture files, works offline): wood planks, floor tiles, stone, carpet and concrete floors; wall tiles where the room's tiling says (square tiles for full tiling, small brick-bond tiles for a splashback); plaster walls, skirting, ceilings, window frames and glass, door frames, handles, stone worktops, steel and glass; grass, paving, gravel, deck, water, stone garden walls, hedges and fences outside.
- **Floor in 3D** in a room's side panel picks the floor finish (automatic by room type: wood for living rooms, bedrooms and halls, tiles in kitchens and bathrooms).
- **Look ▾** → **Light**: *Day* has the sun with soft shadows and a sky; *Night* turns the sun off and the room lights on.
- **Look ▾** → **Quality**: *Low* (no shadows, simple reflections) for phones, *Medium* for tablets, *High* (sharper textures, soft shadows, surface relief) for computers. *Automatic* picks it from the device.

### Laser measure (Bosch GLM 400 C)

Draw walls straight from a Bosch laser measure over Bluetooth. Made for the GLM 400 C (sold as GLM 120 C outside the US); the GLM 50 C and GLM 100 C use the same Bluetooth messages.

1. On the laser, turn Bluetooth on in its settings menu. Close the Bosch MeasureOn app if it is connected, since the laser talks to one app at a time.
2. Click **Laser**, the orange button at the top, left of **Plan**. The installed app lists the lasers it finds (it reconnects to the last one by itself next time); Chrome and Edge show their own Bluetooth picker. When it's connected the button turns blue and reads **Read**.
3. Click **Read**. The first time, tap the plan at the inside corner where the first wall starts.
4. In the window, set the wall's angle (0° points right, 90° up; quick buttons for 0, 90, 180 and 270) and which side the room is on, then take one measurement on the laser. The wall is drawn as soon as the reading arrives.
5. Click **Read** again for the next wall; it continues from the end of the last one and the corner is joined. When a wall ends back at the first corner the room closes, and the next **Read** starts a new run.

- The reading is the room-side face of the wall (measure inside the room, corner to corner); the wall thickness from the Wall tool goes on the outside. Walking around a room in order (0, 90, 180, 270 with the room on the left) gives a closed room with exactly the measured inside sizes.
- A reading taken while the window is closed isn't lost: the next Read window offers **Use last reading**. You can also type a length there.
- **Start somewhere else** begins a new run at a point you tap. Undo removes laser walls as usual, and the next Read continues from the last wall that is still there.
- **Data from the laser** in the Read window shows the raw bytes of the last message, which helps if a different Bosch model sends something unexpected.
- Android asks for the Bluetooth (Nearby devices) permission the first time. The Android app now needs Android 8.0 or newer.
- Not available in Firefox or Safari, which have no Bluetooth for web pages.

### Outdoor (backyard)

The **Outdoor** section in the tool panel has three groups.

**Yard walls:** Fence, Garden wall, Hedge and Railing.
- Draw them like walls: click to start, click each corner, double-click to finish. They join the house walls.
- Each kind has its own look on the plan and in 3D, and its own thickness and height (fence 50 × 1800, garden wall 200 × 1200, hedge 600 × 1500, railing 50 × 1000), which you can change before or after drawing.
- Yard walls never create rooms, so a fenced yard doesn't turn into a room.
- Add a gate with the Door tool.
- Any wall's **Type** can be changed in its side panel.
- Their total lengths appear in the schedule (e.g. *Fence 28.40 m*). They export to AutoCAD on `L-SITE-FENCE`, `L-SITE-GWALL`, `L-SITE-HEDGE` and `L-SITE-RAILING`.

**Ground:** Lawn, Patio paving, Deck, Gravel, Pool / water and Planting bed.
- Click the corners like the Area tool. Edges can be bent into curves for curved beds, pools and paths.
- Each surface has its own pattern on the plan and colour in 3D; a deck is raised.
- Areas are listed under Takeoff in "Measured areas and yard" and copied to the CSV, which gives quantities for sod, pavers, decking or gravel.
- Any measured area's **Surface** can be changed in its side panel.

**Garden:** Tree, Palm tree, Shrub, Planter, Fountain, Fire pit, Pergola / shade, Umbrella, BBQ grill, Dining set, Sun lounger, Garden bench, Hot tub, Swing set and Garden light.

- Fire pit: choose **Circular** (sized by its radius) or **Rectangular** (length and width) before placing it, or switch later in its side panel. Plan and 3D follow the shape.
- Place them anywhere; garden items don't snap to walls, except the BBQ and bench, which back onto a wall like kitchen units.
- `R` rotates, and size and height are set in the side panel.
- Each has a plan symbol and a 3D model, and is counted in the fixture schedule.

## Using the app

- Zoom: pinch on a touchpad or touchscreen, `Ctrl`+scroll, the **+ / −** buttons at the bottom right of the plan, or the `+` and `-` keys. **Fit** shows everything.
- First start: the app asks how to begin — **Blank page**, **Start with an example** (a small flat with a kitchen, bathroom and living room), or **Open a project file…**. Later starts reopen your tabs as you left them; **+** gives the same choice of blank or example.
- Leaving the app: the Android back button first steps out of whatever is open (a dialog, Walk mode, the details panel, a tool, a selection). Then it exits. With autosave on, projects that already have a file are saved quietly first. Each project that still has unsaved changes is asked about in turn (**Save** / **Don't save** / **Cancel**), and its tab closes after the answer. When nothing needs saving it just asks "Exit Benchmark Planner?" and says the work is saved (or saved automatically). Closing the window on a computer works the same way.
- **Electric plan** (button next to Plan; available once the plan has at least 4 walls and 1 light, switch or socket): a separate wiring plan over the home plan. The home plan and its lights, switches and sockets are locked there. Tools: AC and DC wires (size in mm² or AWG, cores, coloured by size, DC dashed, curved or straight, ends snap to lights/switches/sockets/parts, a connector per end, circuit), conduits (type, diameter, which wires are inside, fill %), junction boxes, breaker panel (main breaker, main feed wire, breakers with size, poles and type), grid supply, and the solar chain (solar panels, DC isolator, inverter, battery, solar breaker). Wire lengths count the run on the plan, up/down to each end's height, and a spare %. The **Worksheet** lists everything with sizes, lengths and quantities, and saves as CSV with empty price columns. On the home plan the wiring shows faded; the **Wiring** button hides it.
- Electric plan info: **Measures › Electric plan** shows or hides all wire, conduit and part info (names, sizes, lengths, breakers). With it off, any selected item can still show its own info (**Show its info on the plan** in its panel). Each breaker in the panel has a name, size, poles, type and **Feeds** (the junction box or part it supplies); a wire from the panel to that junction box goes on the breaker by itself. The worksheet and CSV include a breaker schedule.
- Wall corners: walls joined end to end are mitred at any angle (in the plan and in 3D), and a wall ending on the side of another stops at its far face, so nothing sticks out of a corner. Ends that are not snapped together stay square, so an unjoined corner is easy to spot.
- Electric plan wiring of lights: a wire snaps exactly to the nearer end of a strip light, a spot light takes only one wire, and a strip light one wire at each end (two in all); another one is refused with a message. Chandeliers, wall lights, switches, sockets and wiring parts can take several.
- Copy and paste lights, switches and sockets: select one or several (Ctrl/Shift+click or a selection box), press **Copy** or Ctrl+C, then Ctrl+V (or **Paste**) and click where they go. Wall-mounted parts land on the wall nearest their new spot. Copying walls or a room also copies the electrical parts on them.
- Units (mm, cm, m, ft-in) are in the **File** menu. They are one setting for the whole app: every open project shows them, and the app starts with the last units you picked. **Measures** (which dimensions show on the plan) is in the top bar.
- The window (computers): the app remembers the window's size, position and maximized state from the last time it was closed, and always keeps the window inside the visible part of the screen, so its bottom bar is never behind the Windows taskbar.
- Two-finger pinch on a touchpad or touch screen zooms the plan in the desktop app too (it no longer zooms the whole app; Ctrl +/- are blocked for the same reason).
- Starting the app: every start, including after an exit, asks how to begin: **Continue "<last project>"** (the last project you saved or opened, with its file name), **Blank page**, **Start with an example**, or **Open a project file…**. If the app was closed without exiting (for example, swiped away) while work was unsaved, **Recover unsaved work** brings those tabs back.
- A project saved to a new file takes that file's name (saving as "Kitchen plan.bench.json" names the project "Kitchen plan").
- On a phone, the side panel (sizes and settings of what you select, takeoff and schedule) slides up from the bottom when you tap something, and the plan moves so your selection stays in view. **Details** at the bottom left of the plan opens or closes it at any time; **Close** or the grab bar hides it.
- Tool panel (left): click « or press `[` to fold it to an icon rail, and click a section title (Draw, Kitchen, Bath) to fold that section. Hover an icon for its name.
- `V` Pointer: drag a wall to push or pull it, or turn on **Free move** (`M`, or hold `Shift`) to drag it in any direction. Drag an end square to change length. Arrow keys move the selection 10 mm (`Shift`: 100 mm).
- Several walls: drag a box on empty space (left to right = fully inside, right to left = touching) or `Ctrl`+click. Drag any of them to move the group.
- Joints: **Unsnap wall** / **Unsnap from others** lets walls move without dragging their neighbours (loose ends show orange circles); **Snap ends** joins them again. `S` turns snapping on and off.
- Units: mm, cm, m or ft-in in the top bar. Typed numbers use the current unit unless you add one (`3600mm`, `3.6m`, `12'6"`).
- `C` Column / pillar: set shape (square/rectangular or round), length and width or diameter (presets or typed), height and angle, then click to place. It drags freely, including into walls, and clicks against a wall face, flush with the far face, centred in the wall, or in line with another column; sides that meet a wall face show blue connection bars. Select a placed column to type its exact distance to the walls on each side (negative = set into the wall), drag it, or nudge it with the arrows. To turn it, drag the round handle above it (snaps to 15°, `Shift` for any angle), type an exact angle, use the ↺/↻ 15°, ↻ 90° and Reset buttons, or press `R` for 90°. Columns reduce the room's floor area and add to its wall and skirting quantities, appear in 3D, and export to AutoCAD on `A-COLS`.
- Copy and paste: select a wall (or several), a room, a column, a fixture, a door or window, or a dimension and press `Ctrl+C` (or **Copy** in the side panel). `Ctrl+V` (or **Paste** on the plan) gives a copy that follows the pointer by its top-left corner; click to place it. Copied walls join existing wall ends they meet; a copied door or window is placed on whichever wall you click. **Copy room** takes the room's own stretch of each wall with its doors, windows, fixtures, columns, name and tiling. `Ctrl+D` copies and starts pasting in one step.
- `L` Ruler: click two points, or drag, to measure length, angle, across and up/down. Snaps to wall corners, fixture corners and wall faces; on a face it measures square from the first point (the true clear distance). `Shift` for any angle. `Enter` or **Keep as dimension** pins it on the plan; kept dimensions are saved with the project, exported to AutoCAD on `A-ANNO-DIMS`, and deleted with the Pointer + `Del`.
- `A` Curved wall: click the start, click the end (or type the distance and press Enter), then move out to set how far it bends and click, or type a radius and press Enter. It snaps to wall ends and to a half circle; `Shift` bends freely. Select it with the Pointer to drag it, drag an end square (joined walls follow), or drag the round handle to change the bend. The side panel takes an exact radius (the ends stay put), bulge, thickness, height and number of pieces, shows sweep, length along the centre and chord, and has **Flip curve** and **Make straight**. Room areas, wall and skirting quantities, 3D and AutoCAD export follow the curve (it's built from short straight pieces, 6° each by default). In Elevations a curved wall is shown unrolled as one wall. A door or window sits on one piece, so for a wide opening use fewer pieces.
- `D` Door: click the Door tool and pick **Swing door**, **Sliding door, 1 panel** or **Sliding door, 2 panels**, then click on a wall. The tool icon shows the type in use, and the side panel lets you switch type and set the width before placing (`D` reuses the last type). Arrows on the plan show which way sliding panels move; elevations show the panels and 3D shows framed glass panels. A placed door can switch type with **Type** in its side panel, and sliding doors flip to the other side of the wall or (1 panel) slide the other way. Sliding doors are counted separately in the fixture schedule and export to AutoCAD on `A-DOOR`.
- `T` Text: click where the text goes, type, and press `Enter` (`Shift+Enter` for a new line, `Esc` to cancel).
  - Size is the real height of the letters (150 mm to start). Size, angle (with ↻ 90° and Level) and bold are set in the side panel.
  - With the Pointer, drag any text to move it, double-click it to change the words, or press `Delete` to remove it. Copy and paste work too.
  - With the Text tool, click a text in an imported AutoCAD drawing to turn it into a normal text you can move or delete.
  - Room names can be dragged to a better spot. The room's side panel can hide the name or move it back to the centre.
  - Texts are saved with the project and exported to AutoCAD on `A-ANNO-TEXT`.
- `E` Eraser (shown only when something imported is still visible under the plan): everything it can remove is drawn in red. Drag over the imported picture or reference drawing under the plan to rub out lines you don't want: dimension lines, furniture, fixtures, text. Walls, doors and windows you have are never touched. Set the brush size in the side panel. `Ctrl+Z` (or **Undo erase**) undoes a stroke, and **Remove all of it** clears the whole reference. The erased result is saved with the project. The outside measurements with tick marks are the app's own wall dimensions; hide them from **Measures** on the plan.
- `G` Area: measure any shape.
  - Click its corners (3 or more); they snap to wall corners and faces. Click the first corner, double-click or press `Enter` to close. `Backspace` removes the last corner and `Esc` cancels.
  - Double-click inside a room to take its outline; a curved wall becomes one curved edge.
  - Select an area with the Pointer to drag its corners. Drag the round handle on any edge to bend it into a curve; it snaps to straight and to a half circle, and `Shift` bends freely. You can also type an exact bend per edge (minus bends inwards).
  - Double-click an edge to add a corner, or a corner to remove it.
  - **Hide on plan** (in the area's side panel) hides one area but keeps it in the takeoff; click its row in Takeoff to select it and show it again. Turning off **Measured areas** in the Measures menu hides all plain measurements at once.
  - Area and perimeter are exact, curves included. Areas are named, listed under Takeoff with a total, copied to the CSV, saved with the project and exported to AutoCAD on `A-AREA-MEAS`.
- `W` wall: click to start, type a length and press Enter. `3600<90` draws 3600 mm at 90°. On a phone, tap **Type length**.
- `D` door, `N` window: click on a wall; live dimensions show the distance to each wall face.
- Kitchen and bath fixtures: pick one, move near a wall, and it backs onto the wall and snaps to corners and neighbours. `R` rotates.
- **Elevations** view: pick a room to see every wall unfolded, with cabinets, openings, tile zones and heights. Letters A, B, C… in the plan show which wall is which.
- Rooms and areas work together.
  - **Rooms** appear by themselves wherever walls close a space. Click inside one to select it: its corners get square handles and its sides round ones.
  - Drag a corner to move that corner of the room, or a side to push or pull it; the walls move with them, and walls joining part way along stay attached.
  - **Delete** (or `Del`) removes a room from the plan, the takeoff and the elevations, and keeps its walls. Undo, or **Restore** under Takeoff, brings deleted rooms back.
  - **Show elevations** opens that room's walls.
  - **Areas** can be rooms too: set an area's **Kind** to Kitchen, Bathroom, Living, Bedroom, Hall or Other. It then gets the room colour on the plan and in 3D, and its wall surface, wall tile (full-height tiling) and skirting are worked out from the walls along its sides, minus doors and windows. This suits open-plan zones that walls don't close off.
  - Room areas are listed under Takeoff with the same columns as rooms. Elevations and backsplash tiling come from wall-enclosed rooms.
- Click a room to rename it, set its type, and choose tiling (backsplash, or full walls up to a height). Tile areas skip openings, tall units and the wall behind tubs and shower trays.
- Takeoff panel: floor, net wall, tile and skirting per room. **Copy as CSV** pastes into Excel.
- **Measures** (on the plan) chooses which measurements show. Each one can be turned on or off, or use **Show all** / **Hide all**. The choice is remembered.
  - Outside wall dimensions
  - Length of every wall (curved walls along the curve)
  - Door and window widths
  - Measurements while drawing, selecting and moving (wall lengths, distances of doors, windows and columns)
  - Room areas and sizes
  - Measured areas
  - Kept ruler dimensions
- Plan: middle-drag, `Space`+drag, two-finger drag or the **Pan** button to pan; mouse wheel or pinch to zoom; `F` to fit.
